# EasyAI v1.1.0 — Screenshot Index

All screenshots below are real captures of the running EasyAI v1.1.0 (Windows,
local machine, `D:\Programming\EasyAI`), taken by `docs/manual/_capture.py`.
Nothing here is mocked up or hand-edited. Window titles show `v1.1.0` in every
shot. Captured against a fresh-install `settings.json` (backed up before the
run and restored afterward), with `first_run_done` cleared and `auto_launch`
off so **ComfyUI was never started and no job was ever sent** — the engine
pill reads "engine down" throughout, matching the constraint that this
capture must not touch ComfyUI or the user's real `C:\AI` install.

Each row maps a file to the outline section (`docs/manual/outline.md`,
"Screens") it illustrates, with any caveats about empty/fresh-install state.

## Not captured

- **Reference slots 2+ revealed** (outline: "a workflow with several
  Reference N slots revealed"): only the first slot ("Image 1") could be
  shown reliably; automatically filling it to trigger the next slot's reveal
  was attempted but not made robust in this pass.
- **Model picker visible**: requires a ComfyUI models folder with more than
  one file of the same family to scan, which needs pointing EasyAI at a real
  ComfyUI install — skipped per the "don't touch `C:\AI`" constraint.
- **Engine-live states** (Settings' "answering" status, Main Window's
  `engine live` pill, EasyAI Setup's "already running" messaging): all
  require a running ComfyUI, which this capture never starts.
- **Queue tab with running/waiting items, the 20-second close countdown, and
  the "Still working" exit-guard dialog**: all need at least one real queued
  job.
- **EasyAI Setup's "found ComfyUI here" / update-switch line**: needs
  pointing Setup at an existing ComfyUI install (skipped — see above).
- **CHECK SET UP / guessed-binding warning banner** in the Manifest Editor:
  none of the workflows shipped in this repo currently have a non-empty
  `ambiguous` list.

## How this was produced

`docs/manual/_capture.py`:
1. Backs up `settings.json` and `%APPDATA%\EasyAI\language.json`, then writes
   a fresh-install `settings.json` (`first_run_done: false`, `auto_launch:
   false`, workflows/output pointed at this repo's own folders) and forces
   English.
2. Launches `EasyAI.py`, `EasyAISetup.py` and `EasyAIStudio.py` as real
   subprocesses (never `QT_QPA_PLATFORM=offscreen`), driving them with
   `pywinauto` (win32 backend for window discovery/screenshots, UIA backend
   for clicking tabs/buttons/menus) and capturing pixels with `pyautogui`.
3. Restores `settings.json` and `language.json` when done, regardless of
   success/failure.

No ComfyUI process was started, no job was queued, and nothing outside
`docs/manual/` was left modified in the repository.
